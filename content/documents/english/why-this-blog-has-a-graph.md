# Why this blog has a graph

A chronological archive answers one useful question: what was published recently? It does not show which ideas reinforce each other or where an unexpected path crosses between technical and personal work.

Every internal document link creates a connection. The graph simply makes those editorial choices visible. It can lead from [building useful AI systems](/blog/building-useful-ai-systems) to [learning in public](/blog/learning-in-public), then into [photography as observation](/blog/photography-as-observation).

## The graph is navigation

The graph should help someone choose what to read next. It is not a score, and highly connected documents are not automatically more important.

Start with [welcome to the blog](/blog/welcome-to-the-blog) for the full orientation.
